# Quickstart: Run the SMA Crossover Analysis (minimal reproducible)

This quickstart shows the minimal steps to run the canonical analysis for a short smoke test.

1. Create a Python environment and install requirements (use pinned `requirements.txt`).

2. Run the analysis for a single ticker (smoke test):

```
Create a `config.yaml` in the current directory with the required keys and then run the CLI with no arguments:

```
tickers: ["AAPL"]
start_date: "2014-01-01"
end_date: "2018-12-31"
sma_pairs: [[5,20]]
holding_periods: [10]
output_dir: "outputs/test_run"
```

Then execute:

```
python -m sma_analysis.cli run
```
```

3. Expected artifacts (smoke run):

- `outputs/test_run/sma_crossover_analysis_results_{RUN_TS}.csv` (one row per aggregation)
- `outputs/test_run/heatmap_avg_mean_return_10d_{RUN_TS}.png` (heatmap with masked cells)
- `outputs/test_run/analysis_summary_{RUN_TS}.md` (short summary)
- `outputs/test_run/logs/na_fill_warnings_{RUN_TS}.csv`

4. Smoke checks (automated at end of run):

- Files exist and are non-empty.
- `Num_Signals_Used` column present and numeric.
- `P_Value` within [0,1] or NA for low-power rows.

5. To reproduce exactly: record the `run_manifest_{RUN_TS}.json` and `requirements_exact_{RUN_TS}.txt` generated by the run.

Notes:
- For full canonical run use the default SMA pairs and date range defined in the spec.
-- Use `workers` and `batch_size` in `config.yaml` to tune performance on your machine.
